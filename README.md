## 📱 Projet phare : Application de suivi du paludisme

Une application mobile destinée au personnel soignant pour faciliter le suivi des patients atteints de paludisme.

### Fonctionnalités prévues

- Comptage automatique des cas de paludisme en fin de mois
- Suivi des cures de traitement et des rechutes
- Gestion simultanée de nombreux patients
- Identification des patients par leur nom
- Accès multi-utilisateurs sécurisé par mot de passe
- Stockage local des données sur le téléphone (sans dépendance à une connexion internet)

### Statut du projet

🚧 **En cours de développement** — l'application est actuellement codée en interne.

Objectif : usage personnel dans un premier temps, puis commercialisation auprès d'autres professionnels de santé.
